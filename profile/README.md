# Tiztel Software

Tiztel Software builds governed software delivery systems and practical automation for business operations.

Our engineering model treats GitHub as the authoritative record for specifications, work, source, review, validation, release evidence, and audit history.

## Operating principles

- Human authority remains explicit
- Work begins from written acceptance criteria
- Automated agents receive narrow permissions and write scopes
- Pull requests and passing validation are mandatory
- Secrets and client data do not belong in source control
- Reusable controls are preferred over repository specific copies

Public repositories contain material intentionally approved for public release. Product code and internal delivery records are private unless explicitly classified otherwise.
