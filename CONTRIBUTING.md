# Contributing

Tiztel Software repositories use governed, issue driven delivery.

Before proposing a change:

1. Open or identify the GitHub issue that authorizes the work.
2. Confirm the acceptance criteria and authorized write scope.
3. Use a focused branch for one work item.
4. Add or update tests and documentation.
5. Run required validation.
6. Open a pull request using the provided template.

Do not include credentials, private keys, tokens, client data, personal information, or internal incident details.

Maintainers may close submissions that lack authorization, exceed scope, weaken security controls, or do not provide adequate validation evidence.
