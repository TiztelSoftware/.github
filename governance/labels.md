# Standard Labels

| Label | Purpose |
| --- | --- |
| `type:architecture` | Architecture decision or design |
| `type:defect` | Reproducible product or platform defect |
| `type:implementation` | Approved implementation work |
| `type:integration` | External system or service integration |
| `priority:critical` | Immediate material risk or outage |
| `priority:high` | Important work with near term impact |
| `priority:normal` | Standard planned work |
| `priority:low` | Useful but not time sensitive |
| `status:blocked` | Cannot proceed without a dependency or decision |
| `status:ready` | Authorized and ready for execution |
| `security` | Security relevant work requiring restricted handling |
| `agent:eligible` | Work may be assigned to an approved agent |
| `human:required` | Human judgment or authorization is required |

Repositories may add domain labels. They must not redefine the meaning of organization labels.
