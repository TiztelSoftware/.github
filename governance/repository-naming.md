# Repository Naming

Repository names use lowercase words separated by hyphens.

## Patterns

- Product: `product-name`
- Service: `product-service-name`
- Shared library: `library-purpose`
- Infrastructure: `infra-purpose`
- Template: `purpose-template`
- CI components: `ci-purpose`
- Archive: retain the original name and use GitHub archive status

Names must describe purpose, not teams, temporary initiatives, people, clients, environments, or implementation technology unless the technology is the product boundary.

Do not encode confidential client names or contract identifiers in repository names.
